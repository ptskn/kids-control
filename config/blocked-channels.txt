# kids-control — blocked YouTube channels
# One channel handle per line, starting with @ :
#
#   @SomeChannel
#
# The handle is in the channel page URL: youtube.com/@SomeChannel
# Effect: the channel page won't load, and every video card linking to
# that channel is hidden (home, search, suggestions, subscriptions).
#
# After editing, re-run:  sudo /opt/kids-control/install.sh
#
# Example (remove the leading # to activate):
#@SomeChannel
